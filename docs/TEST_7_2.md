## 2. 오류 응답 (서버 · DB) — 실서버에서 확인, 데이터 변경은 모두 되돌림
| 상황 | 기대 | 결과 |
|---|---|---|
| 비로그인 사용자 레시피 조회 | 허용 | ✅ 13개 조회 |
| 비로그인 사용자 관리자 기능 호출 | 차단 | ✅ 거부 (42501) |
| 비로그인 사용자 찜 추가 | 차단 | ✅ 거부 |
| 일반 회원 관리자 기능 호출 | 차단 + 안내 | ✅ "관리자만 사용할 수 있어요" |
| 남의 레시피 수정·삭제 | 0건 처리 | ✅ 수정 0건 · 삭제 0건 |
| 남의 레시피를 수정 함수로 수정 | 거부 + 안내 | ✅ "내가 등록한 레시피만 수정할 수 있어요" |
| 일반 회원 재료 DB 추가 | 차단 | ✅ 거부 |
| 같은 게시물 두 번 신고 | 차단 | ✅ 중복 거부 (23505) → 화면에는 "이미 신고한 게시물이에요" |
| 빈 레시피 등록 | 거부 + 안내 | ✅ "요리 이름을 입력해 주세요" |
| 관리자 대시보드 | 허용 | ✅ 정상 |
| 추천 함수 응답 시간 (실서버, 재료 5개) | 3초 이내 | ✅ 4.9 ms |

## 3. 회귀 · 시나리오 · 예외 처리 (자동 테스트)
`frontend/tests/regression.mjs` — 배포와 같은 빌드를 체험 모드로 띄워 실제 화면을 눌러 보는 테스트 25개.
실행: `cd frontend && npm run test:regression` (처음 한 번 `npm i -D playwright && npx playwright install chromium`)

결과: **Galaxy S24 25/25 통과, Pixel 7 25/25 통과** — 항목별 결과는 `frontend/tests/regression-result.md`

| 구분 | 테스트 |
|---|---|
| 재료·추천 | 재료 담기→추천→일치율, 재료 빼기 동기화, 최근 검색어, 별칭 검색 |
| 레시피 | 레시피 검색, 인분 환산·10단계 이상, 조리 모드 단계·타이머, 찜 |
| 업로드 | 등록 → 내 레시피 → 수정 → 삭제 |
| 커뮤니티 | 후기·평균, 질문·업로더 답변 |
| 관리자 | 신고 → 숨김 → 해제, 재료 추가·별칭·삭제, 공지 배너 |
| 예외 | 재료 0개 추천, 없는 재료, 여러 재료 중 없는 재료, 중복 신고, 빈 제목 등록, 없는 레시피 주소, 없는 페이지, 인터넷 끊김, 뒤로 가기로 창 닫기, 가로 화면 |
